# 2G Ethanol Technology Provider Reference

Same purpose as the sibling repos' `docs/VENDOR_REFERENCE.md` documents:
does a named provider's own (or independently reported) real project
confirm a genuine, verifiable detail this project's sizing can be
cross-checked against — not vendor endorsement.

| Provider | Source | What it confirms | Relevance to this repo |
|---|---|---|---|
| **Praj Industries** | Widely reported (biofuels-news.com, indianchemicalnews.com, chinimandi.com) as the technology provider behind IOCL's Panipat 2G ethanol biorefinery, inaugurated by the Prime Minister; the same real, India-headquartered (Pune) company already verified in the sibling ethanol-design-opensource repo's own `docs/VENDOR_REFERENCE.md` for 1G dehydration technology (EcoMol/MaxImol). | Confirms Praj as a real technology provider spanning BOTH the 1G (molasses/grain) and 2G (lignocellulosic) fuel-ethanol process this project family covers across two separate sibling repos — the plant this repo's own worked example is sized against (IOCL Panipat, 425.7 t/day rice straw, 100 KLPD nameplate) is Praj's real, commissioned, commercial installation, not a hypothetical. | Real-world grounding for the whole worked-example validation exercise in `docs/VALIDATION.md` — the 425.7 TPD / 100 KLPD figures and the "62% of design capacity" operational finding both trace to this same real plant. |

## What didn't clear the verification bar

No public Praj page with quantified pretreatment/hydrolysis/co-
fermentation process parameters (severity factor, enzyme loading,
xylose recovery) specific to the Panipat plant was found or
independently fetched for this document — real commercial process
performance data of this kind is evidently held back for direct
engagement, the same gap the sibling ethanol-design-opensource repo's
own vendor document found for 1G dehydration specifications.

## Note on this document's scope

Deliberately the smallest `VENDOR_REFERENCE.md` in this project family:
2G cellulosic ethanol is a young, thin commercial market in India (one
operating commercial plant, IOCL Panipat, as of this writing), so there
is essentially no independent, competing technology-catalog tradition
yet to cross-check against — unlike the sibling repos' larger
component-catalog or multi-EPC-firm documents.
